# Student Management System

A console-based Student Management System developed using Java.

## Features

- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Duplicate Student ID Validation
- Age Validation
- Save and Load Student Records using File Handling

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Git & GitHub
